📖 API Documentation

Integrate LeadScraper Pro into your own applications

Base URL

http://localhost:5000

Endpoints

POST/api/jobs

Create a new scraping job.

Request Body:

{"query": "plumbers in Austin TX", "sources": ["google_maps", "website_contacts"], "max_results": 20}
GET/api/jobs

List all scraping jobs.

GET/api/jobs/{job_id}

Get a specific job with its leads.

GET/api/jobs/{job_id}/leads

Get all leads for a specific job.

GET/api/jobs/{job_id}/export/csv

Download leads as CSV.

GET/api/jobs/{job_id}/export/xlsx

Download leads as Excel.

GET/api/stats

Get dashboard statistics.

WSWebSocket: /socket.io

Real-time job progress updates via Socket.IO.

Quick Start Examples

cURL:

# Start a scrape
curl -X POST http://localhost:5000/api/jobs \
  -H "Content-Type: application/json" \
  -d '{"query": "restaurants in NYC", "sources": ["google_maps"], "max_results": 10}'

# Get results
curl http://localhost:5000/api/jobs/{job_id}

# Export as CSV
curl -O http://localhost:5000/api/jobs/{job_id}/export/csv

Python:

import requests

resp = requests.post("http://localhost:5000/api/jobs", json={
    "query": "dentists in Chicago",
    "sources": ["google_maps", "website_contacts"],
    "max_results": 20
})
job_id = resp.json()["job_id"]

import time
while True:
    status = requests.get(f"http://localhost:5000/api/jobs/{job_id}").json()
    if status["status"] == "completed":
        break
    time.sleep(2)

leads = requests.get(f"http://localhost:5000/api/jobs/{job_id}/leads").json()
print(f"Found {leads['count']} leads!")

JavaScript (fetch):

const res = await fetch("/api/jobs", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ query: "lawyers in Miami", sources: ["google_maps"], max_results: 15 })
});
const { job_id } = await res.json();

const socket = io();
socket.emit("subscribe_job", { job_id });
socket.on("job_update", (data) => console.log(`Progress: ${data.progress}%`));
